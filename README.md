# Inventory System Pro

A modern, Clean Architecture-based Inventory Management System built with Blazor Server, EF Core, and PostgreSQL.

## Architecture
This project implements the **Repository Pattern** to separate data access logic from business logic, ensuring highly testable and maintainable code.

## Running Tests
To run the automated test suite, execute the following command from the root folder:
```bash
dotnet test Tests/InventorySystem.Tests.csproj
```
